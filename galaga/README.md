# 🛸 Galaga Retro Arcade (갤러그 레트로 아케이드)

HTML5 Canvas 기반으로 완벽히 구현된 고전 아케이드 슈팅 게임 **갤러그(Galaga)** 배포 번들입니다. 추가적인 외부 종속성 없이 모든 기기에서 즉시 실행이 가능하며, 오프라인 플레이를 지원하는 PWA 규격을 갖추고 있습니다.

## 📦 배포 패키지 구성
- `index.html`: 게임 실행 메인 HTML 파일 (최종 검증 완료 소스 및 PWA 적용)
- `manifest.json`: PWA 앱 정보 설정 파일 (홈 화면 추가, 오프라인 실행 및 테마 색상 설정)
- `sw.js`: 서비스 워커 스크립트 (오프라인 캐싱 및 구동 자동화)
- `icon-192.png` / `icon-512.png`: PWA 및 파비콘 대응용 아이콘 파일
- `start_server.py`: 로컬 서버 실행용 파이썬 스크립트 (자동 포트 스위칭 및 브라우저 기동)

## 🎮 게임 조작 방법

### 💻 PC (키보드 조작)
* **좌우 이동**: `◀` / `▶` (방향키) 또는 `A` / `D` 키
* **미사일 발사**: `Spacebar` 키
* **게임 일시정지 / 재개**: `P` 키
* **게임 오버 시 재시작**: `Enter` 키

### 📱 모바일 / 태블릿 (가상 터치 패드)
* 화면 하단 좌측에 위치한 **`◀` 및 `▶` 가상 버튼**을 터치하여 우주선을 좌우로 이동합니다.
* 화면 하단 우측에 위치한 **빨간색 발사(Fire) 버튼**을 터치하여 미사일을 발사합니다.
* 뷰포트 및 메타 태그가 모바일 환경에 맞춰 최적화되어 있어, 세로 모드(Portrait)로 원활하게 플레이할 수 있습니다.

## ⚡ 로컬 실행 방법 (파이썬 웹서버 구동)

오프라인 캐싱 및 PWA의 모든 기능을 로컬에서 완벽하게 테스트하려면 HTTP 서버 환경이 필요합니다. 아래 명령어로 번들링된 경량 서버를 즉시 기동할 수 있습니다.

### 1. 실행 명령어
게임 디렉토리 내에서 아래 명령을 실행합니다.
```bash
python3 start_server.py
```

### 2. 특징
* 실행 즉시 사용 가능한 웹 브라우저 창이 자동으로 오픈됩니다.
* **자동 포트 스위칭 (Port Switching)**: 기본값인 `8000`번 포트가 이미 다른 프로세스에 의해 사용 중일 경우, `8001`번 이후의 사용 가능한 빈 포트를 탐색하여 자동으로 스위칭합니다.

## 📱 PWA (Progressive Web App) 설치 및 오프라인 이용
이 배포 번들은 서비스 워커와 매니페스트 설정을 포함하고 있어 기기에 설치하여 네이티브 앱처럼 실행할 수 있습니다.

### Chrome / Edge (데스크톱)
1. `start_server.py`를 실행하여 브라우저로 접속합니다.
2. 주소창 우측의 **앱 설치 아이콘(🖥️+)**을 클릭합니다.
3. 바탕화면에 바로가기가 생성되며 오프라인 상태에서도 실행이 가능합니다.

### iOS / Android (모바일)
1. 모바일 브라우저(Safari, Chrome 등)를 통해 서버에 접속합니다.
2. **'홈 화면에 추가'**를 선택합니다.
3. 홈 화면에 생성된 갤러그 아이콘을 탭하면 브라우저 주소창 없이 전체 화면 앱 모드로 오프라인 구동됩니다.
